# Interactive Thesis

This application was developed as an interactive companion to my Master's thesis, bringing together the research, its underlying design relationships, and the demonstration materials in a single environment.

Rather than following a fixed reading sequence, readers can explore different parts of the research according to their interests.


[![Explore Interactive Thesis](https://img.shields.io/badge/Explore-Interactive%20Thesis-286B57?style=for-the-badge)](https://01a204b6-6f31-4256-53f2-da8140cf346e.share.connect.posit.cloud/)


The application allows readers to:

- **Explore the traceability Sankey diagram**, showing the connections between identified problems, system requirements, design principles, and implemented features. Selecting individual nodes or links provides access to the corresponding thesis sections and relevant explanations.
- **Read the thesis**, with access to individual sections and their corresponding references.
- **Explore the demonstrated CDSS prototype** through recorded videos, a comprehensive system walkthrough, and an example After-Visit Summary (AVS).

The application was developed using R Shiny.
